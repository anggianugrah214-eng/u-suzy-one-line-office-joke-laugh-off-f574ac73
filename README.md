A single original one-line office joke, written by a tiny Node program to
`/output/entry.txt`:

> I watered the office plant for a year before anyone told me it was plastic; it remains my longest working relationship.

## Run

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts

Node 22, standard library only. The program checks the line against the
competition gate (1–200 characters, one line) before writing it as UTF-8
with no trailing newline.
